# Lunch Forge v0.4.0

MTGスタンダード向け、日本語優先のカード・デッキ解析ツールです。

## v0.4.0 の主な追加

### Knowledge Engine α

- スタンダード全カードの知識タグを一括集計
- タグ付与率、平均タグ数、解析信頼度を表示
- タグ別のカード分布を可視化
- 未分類・低信頼度カードを抽出
- カード名・タグ・グループから知識プロフィールを検索
- 現時点の知識データをJSON形式で書き出し

### 設計方針

この版は外部デッキサイトを自動収集しません。カード本文から得られる構造的な知識を先に整備し、将来、利用条件を確認できた大会データやデッキデータを別レイヤーとして統合できる構成にしています。
