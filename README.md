# Lunch Forge v0.3.1

MTGスタンダード向けカード検索・日本語表示・デッキ分析・カード知識解析ツールです。

## v0.3.1 の主な追加

- 「カード解析」タブ（Card Inspector）
- 日本語・英語カード名から1枚を解析
- 生成／利用／誘発／補助／妨害／戦略／勝ち筋の分類
- 得意なこと、必要な支援、注意点を日本語表示
- スタンダード全カードから相性候補を自動採点
- 最近解析したカードをブラウザに保存
- カード検索で自然な日本語の意味検索を追加
  - 例：宝物を作る、墓地を使う、全体除去、横並べ
- 日本語カード画像・正式日本語名・日本語ルール文章を優先表示

## 更新方法

`index.html`、`styles.css`、`app.js`、`README.md` をGitHubリポジトリのルートへ上書きアップロードしてください。

コミット例：

```text
Add Card Inspector v0.3.1
```

更新後は `Ctrl + F5` でキャッシュを無視して再読み込みしてください。
