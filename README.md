# Lunch Forge v0.2.0

MTGスタンダード向けカード検索・デッキ分析・相性提案ツールです。

## v0.2.0 の主な追加

- Card Knowledge Base（カード辞書）
- 日本語の目的検索
- 生成・利用・誘発・補助・妨害・勝ち筋の分類
- カード詳細画面の知識プロフィール
- 単体カード相性の方向性スコア
- 相性理由と注意点の表示

## 公開

GitHub Pagesのルートへ `index.html`、`styles.css`、`app.js`、`README.md` を配置してください。

カードデータと画像はScryfall APIを利用します。
