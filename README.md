# Lunch Forge v0.6.7a

## Consistency & Timing Engine β-7

Rule Path / Strategy Value に続き、現在のデッキリストを使ってシナジーの再現性と成立タイミングを評価します。

### 主な機能
- ルール検証ページから現在のデッキ入力を参照
- 必要カードの採用枚数を集計
- 先攻 / 後攻を切り替えて3T・4T・5Tの自然ドロー到達率を計算
- 必要カードの合計MVからマナ上の理論最速ターンを表示
- 現在の土地枚数から最速ターン時の土地到達率を計算
- 固定色シンボルと色マナ源から色拘束を一次評価
- ドロー / サーチ / 衝動的ドロー / 切削をアクセス補助手段として集計
- コンボパーツ単体で引いた場合の依存度を一次評価
- Consistency score（0～100）とA～E評価を表示

### 確率表示について
3T / 4T / 5Tの「自然到達率」は、初手7枚から通常のドローだけで必要カードをすべて1枚以上引く確率です。マリガン、追加ドロー、サーチ、切削、占術、相手の妨害は含みません。アクセス補助手段はConsistency scoreへの定性的補正だけに使用し、表示している自然到達率そのものは変更しません。

### デッキが入力されていない場合
60枚デッキ・各必要カード4枚採用という仮定で参考値を表示します。実際の採用枚数で評価する場合は、デッキ分析ページにデッキリストを入力した状態で「デッキ分析ページの現在のデッキリストを再現性評価に使用」を有効にしてください。

## v0.6.7a timing hotfix
- 「マナ上の理論最速」を印刷MVの単純合計だけで決めないよう修正。
- Verified Rule Pathでは実際に唱えるカード、代替コスト、墓地から戻すための支払い、必要な土地配置を時系列で評価。
- 月影＋血茨のフレイル＋炎跡のフェニックスは2T、アナグマモグラの仔＋寓話の小道は通常土地展開のみなら3Tを最速経路として扱う。
- 未検証の組み合わせは従来の印刷MVベース計算を暫定フォールバックとして明示。
