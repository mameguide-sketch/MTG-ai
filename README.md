# Lunch Forge v0.2.1

MTGスタンダード向けカード検索・デッキ分析・相性探索ツールです。

## v0.2.1 日本語カード表示

- Scryfallの日本語版印刷データを取得
- 正式な日本語カード名を表示
- 日本語版カード画像を優先表示
- 日本語ルール文章・タイプ行を表示
- 日本語名と英語名の両方で検索
- 日本語名で単体カード探索とデッキ解析
- 日本語版がないカードは英語へ自動フォールバック
- 日本語優先／英語表示の切り替え

カードの分析自体は、表現差による誤判定を抑えるため英語Oracleテキストを基準に行います。表示と検索には日本語データも利用します。
