# Lunch Forge v0.6.8

## Game Plan Engine β-8

Rule Path（ルール上つながるか）、Strategy Value（実戦で扱いやすいか）、Consistency（揃うか・何ターン目か）に続き、組み合わせが**デッキ全体の勝ち方へどれだけ貢献するか**を評価します。

### 主な機能
- 各カードを主エンジン / 成立支援 / 利益変換 / フィニッシャー / 妨害 / 安定化支援などへ分類
- 序盤 / 中盤 / 終盤の担当を可視化
- シナジー不成立時の単体価値を一次評価
- 現在のデッキ内で同じ役割を持つカード枚数を数え、役割重複を評価
- 組み合わせ自身が勝ち筋を持つか、デッキ内フィニッシャーへ引き継ぐか、終端が不足しているかを表示
- Rule Pathが強くてもデッキ内で役割が余っている場合は採用優先度を下げる
- 単体カード探索 / 構築相談 / デッキ分析の推薦順位へGame Plan適合度を反映

### 評価の考え方
Game Plan scoreは勝率ではありません。カードの役割、供給→利用接続、勝ち筋、単体価値、役割重複、現在のデッキ構造から「このデッキで採用する意味」を一次評価します。

表示する勝ち筋は3段階です。
- **Direct**: 解析したカード群自身に勝ち筋タグを検出
- **Indirect**: 解析したシナジーから現在のデッキ内フィニッシャーへ価値を引き継ぐ推論
- **Open End / Incomplete**: 最終的にゲームを終わらせる経路をまだ検出できない

## Consistency & Timing Engine β-7a
- 自然ドロー到達率、採用枚数、土地到達率、色マナ難度、アクセス補助を評価
- Verified Rule Pathでは印刷MVの単純合計ではなく実際の支払い経路から理論最速を判定
- 月影＋血茨のフレイル＋炎跡のフェニックスは2Tを最速経路として扱う
